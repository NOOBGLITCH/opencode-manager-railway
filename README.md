# OpenCode Manager (Railway)

Mobile-first web interface for OpenCode AI agents, deployed on Railway.

Image: `ghcr.io/chriswritescode-dev/opencode-manager:latest`
Default port: `5003`

## Default credentials

- Admin password default: `OC-workspace-2026!` (`ADMIN_PASSWORD`)
- Change `AUTH_SECRET`, `ADMIN_PASSWORD`, and OAuth credentials before production use.
